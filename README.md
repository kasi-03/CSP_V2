# Voice-Based AI-Assisted Police Complaint Drafting System

A modular full-stack application designed to assist citizens and police personnel in drafting formal, structured police complaints in both Telugu and English from voice narrations or audio uploads.

> [!NOTE]
> **Legal Disclaimer:** Documents generated by this application are AI-assisted draft complaints intended for citizen convenience and review. They do not constitute officially registered First Information Reports (FIRs) until verified, processed, and entered into official records by authorized law enforcement personnel.

---

## ⚙️ Prerequisites & Setup

### 1. Requirements
- **Operating System:** Windows 10/11
- **Python:** Python 3.10+ (tested with Python 3.13)
- **Google Chrome:** System Google Chrome browser for PDF rendering

### 2. Environment Configuration
Create or edit the `.env` file in the project root:
```ini
GROQ_API_KEY=your_actual_groq_api_key_here
SECRET_KEY=replace-with-a-long-random-secret
BASE_URL=http://127.0.0.1:5000
```
*(Do not commit `.env` or share API keys.)*

### 3. Install Dependencies
```powershell
pip install -r req.txt
```

---

## 🚀 Running the Application

Start the application on Windows using:
```powershell
python app.py
```

The application will be accessible in your web browser at:
`http://127.0.0.1:5000/`

## 🧪 Running Tests

The automated test suite covers all database operations, route handlers, static assets, Groq AI drafting, and PDF generation.

To run all tests:
```powershell
python -m unittest discover -s tests -p "test_*.py"
```

To run individual test modules:
```powershell
# Backend Services
python -m unittest tests/test_services.py

# Route & Asset Delivery
python -m unittest tests/test_routes.py

# AI, Speech & PDF Generation
python -m unittest tests/test_ai_speech_pdf.py
```

## 🌐 Routes & Endpoints

| Route | Method | Endpoint Name | Description |
| :--- | :---: | :--- | :--- |
| `/` | `GET` | `dashboard` | Dashboard with case counts and table |
| `/record` | `GET` | `record` | Browser microphone recording / audio upload |
| `/process` | `POST` | `process` | Audio transcription, AI drafting, & storage |
| `/settings` | `GET` | `settings` | Police station metadata settings |
| `/save_settings`| `POST` | `save_settings` | Updates station metadata with AI translation |
| `/view_telugu/<id>` | `GET` | `view_telugu` | Formal Telugu complaint paper view / print |
| `/view_english/<id>`| `GET` | `view_english` | Formal English complaint paper view / print |
| `/english` | `GET` | `english` | Most recently generated English draft |
| `/case_audio/<path>`| `GET` | `serve_case_audio` | Stream complaint audio files for browser |

## 🔒 Security & Data Protection
- Secret keys and Groq API tokens are loaded exclusively from `.env` on the server and are never exposed to browser clients or logs.
- SQLite queries use parameterized placeholders (`?`) to prevent SQL injection.
- Git ignores private data directories (`audio/`, `case_records/`, `generated/`), backups (`_backup_pre_refactor/`), and `.env`.
